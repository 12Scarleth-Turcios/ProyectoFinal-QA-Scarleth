# ProyectoFinal-QA-Scarleth

1. Nombre del proyecto
PinQA

2.Integrante
Scarleth Turcios

3.Objetivo del testing
Comprobar la funcionalidad de la épica Pinterest Web a través de la ejecución de casos de prueba
que permitieran comprender su flujo a través de la búsqueda, navegación, la visualización de
pines y el comportamiento responive.

4.Alcance 
-Carga de home/feed
-Scroll (carga de más contenido)
-Búsqueda por palabras
-Apertura de un pin y visualización de detalles
-Navegación atrás/adelante del navegador
-Comportamiento responsive usando DevTools (móvil)

Fuera de alcance (qué NO se probará)
-Registro e inicio de sesión
-Funciones que requieran cuenta (guardar pines/crear tableros si obliga login)

4. Entorno de prueba
-Desktop
Window's 7
Chrome 145.0.7632.116
Git/GitHub
Pinterest Web
Excel

-Iphone (IOS 26.1)
Safari
Pinters Web
Grabadora de pantalla

5.Conclusión general (¿el producto está listo para producción?)
El sistema de Pinterst presenta estabilidad en su funcionalidad y adaptabilidad 
responsive; se encontraron puntos de mejora en enlaces externos y en la búsqueda 
de pines con caracteres específicos, no obstante, se considera estar listo
para ser lanzado cuando estos bugs ya no estén presentes.
